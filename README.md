# E-Commerce AI Business Intelligence & Predictive Analytics

An end-to-end data analytics and machine learning portfolio project that demonstrates a complete business intelligence pipeline using Python, SQL, statistics, PySpark, machine learning, Power BI, Streamlit, and a GenAI-ready analytics prompt module.

> **Dataset:** Synthetic e-commerce transaction data created for learning and portfolio purposes. It does not represent real company or customer data.

---

## Project Overview

This project analyzes a synthetic e-commerce dataset containing **100,000 orders** and **19,876 unique customers**.

The project follows a complete analytics workflow:

```text
Raw Data
   ↓
Data Validation
   ↓
SQL Analytics
   ↓
Statistical Analysis
   ↓
PySpark / Big Data Processing
   ↓
Machine Learning
   ↓
Power BI & Streamlit Dashboards
   ↓
GenAI-Ready Analytics Prompt
